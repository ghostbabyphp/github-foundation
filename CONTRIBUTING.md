# Contributing to GitHub Foundations Practice

Thank you for helping me practice GitHub collaboration workflows! Whether you are fixing a typo, adding a study note, or testing out a Pull Request, your contributions are welcome.

## How to Contribute

### 1. Reporting Issues or Suggesting Topics
* Check the **Issues** tab first to see if a similar topic or task already exists.
* Click **New Issue** and select the appropriate template.
* Provide a clear title and description so we can practice labeling and assigning tasks.

### 2. Submitting a Pull Request (PR)
1. **Fork** this repository to your own GitHub account.
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com
   ```
3. **Create a new branch** for your change:
   ```bash
   git checkout -b docs/add-study-note
   ```
4. **Make your changes** and commit them with a clear message:
   ```bash
   git commit -m "Docs: Add notes on branch protection rules"
   ```
5. **Push** your branch to your fork:
   ```bash
   git push origin docs/add-study-note
   ```
6. Open a **Pull Request** against the `main` branch of this repository and link any related issues (e.g., `Closes #1`).
