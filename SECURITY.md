# Security Policy

## Supported Versions

This is a study and practice repository for the **GitHub Foundations Certification**. Only the latest release is actively maintained.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability or Workflow Bug

### 1. Security Vulnerabilities (Private Reporting)
Please **do not** report sensitive security vulnerabilities (such as exposed tokens, secrets, or workflow exploits) through public GitHub Issues.

* **Private Vulnerability Reporting:** Navigate to the **Security** tab of this repository → **Advisories** → click **Report a vulnerability** to open a private security advisory.
* **Response Time:** Because this is a personal practice repository, reports are reviewed periodically for learning purposes (typically within 3–5 days).

### 2. Non-Sensitive Workflow Errors & Broken Links
If you spot a broken Markdown link, typo, or failing GitHub Action that does not expose sensitive data, please open a standard issue using our **[Bug / Workflow Error Template](../../issues/new?template=bug-report.md)**.
