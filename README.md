# GitHub Foundation

## Purpose
This repository documents my hands-on practice and study notes as I prepare for the **GitHub Foundations certification exam**. The goal is to build practical experience across all core exam domains—from basic Git workflows to project management and collaboration—in a single organized space.

## Exam Domains & Practice Steps

### 1. Introduction to Git and GitHub
* [x] Configure Git locally (`git config`) and authenticate with GitHub.
* [x] Practice creating repositories, cloning, and managing `.gitignore` files.
* [x] Master basic commands (`add`, `commit`, `status`, `log`, `push`, `pull`).

### 2. Working with GitHub Repositories
* [x] Create and switch between branches (`git branch`, `git checkout` / `git switch`).
* [x] Resolve intentional merge conflicts locally and via the GitHub UI.
* [x] Organize repository assets using `README.md`, `CONTRIBUTING.md`, and issue templates.

### 3. Collaboration Features
* [x] Fork a repository, make changes, and open a Pull Request (PR).
* [ ] Practice reviewing PRs, leaving inline comments, and linking Issues to PRs using keywords (e.g., `Closes #1`).
* [ ] Set up and participate in GitHub Discussions.

### 4. Modern Development
* [x] Launch a cloud development environment using GitHub Codespaces.
* [ ] Explore basic automation concepts with GitHub Actions.
* [ ] Experiment with GitHub Copilot features and prompts.

### 5. Project Management
* [ ] Create a GitHub Project board (Table and Board views).
* [ ] Organize work using Issues, Labels, Milestones, and Assignees.

### 6. Privacy, Security, and Administration
* [ ] Configure branch protection rules (e.g., requiring PR reviews before merging).
* [ ] Review repository visibility settings (Public vs. Private) and permission levels.
* [ ] Enable Dependabot alerts and review basic security features.

### 7. Benefits of the GitHub Community
* [ ] Explore open-source repositories, GitHub Marketplace, and GitHub Sponsors.
* [ ] Customize my GitHub profile README.

## How to Contribute
While this is primarily a personal study repository, study tips, resource links, and practice scenarios are welcome!
1. **Fork** the repository.
2. Create a new branch (`git checkout -b add-study-tip`).
3. Commit your changes (`git commit -m "Add tip for pull request workflows"`).
4. **Push** to the branch (`git push origin add-study-tip`).
5. Open a **Pull Request** explaining what you added.
